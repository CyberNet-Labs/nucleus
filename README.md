# Nucleus

The macOS, iOS, iPadOS, Windows and Linux client for
[CyberNet Labs](https://cybernetlabs.cc)'s services, built by CyberNet Labs.

This repository holds public releases only — no source code. Development happens in a private
repository; builds are published here under [Releases](../../releases) as they're ready.

## Release channels here

- **Public betas** — pre-release builds, shared for wider testing once a build is ready to leave
  internal testing.
- **Public stable releases** — non-prerelease tags, once a version is genuinely feature-complete
  and polished. None yet — Nucleus is still under active development.
